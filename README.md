# Component DB
Ever been prepared to start a project when you realise you're missing parts?
Component DB is a simple piece of CLI software that allows you to track and manage your electronic components when you're developing the next groundbreaking idea. 

!(Logo)[assets/images/text_logo.png]

- Manually add component entries or upload your Bill Of Materials from applications like KiCAD.
- Generate a list of components you have and what you need to buy 
- Keep a history of past projects to make revisiting them easier

I made this software to learn SQL for my computer science class alongside networking as I intend to host this on my homelab.
